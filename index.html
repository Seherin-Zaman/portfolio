01 Deep Learning · Computer Vision

Brain Tumor MRI Classification

Explainable medical-imaging pipeline with calibrated confidence.

The problem A model that classifies MRI scans accurately still isn’t usable in a clinical workflow unless it can show where it looked and admit when it isn’t sure.

Four-class classification of brain MRI scans (glioma, meningioma, pituitary, no tumour) across 5,600 training and 1,600 held-out test images. I built a from-scratch CNN as an honest baseline, then an ImageNet-pretrained EfficientNetB0 fine-tuned in two stages. On top of accuracy, the pipeline adds Grad-CAM attention maps, reliability diagrams and Expected Calibration Error, and a selective-prediction study that routes low-confidence cases to a “needs specialist review” tier. Backed by 19 passing unit tests and a GitHub Actions CI workflow.

  • 85.3%Test accuracy
  • 0.847Macro F1
  • 0.034Calibration error

02 Machine Learning · Statistics

Academic Stress Analysis

End-to-end ML on real survey data, with the limitations stated up front.

The problem How much of a student’s self-reported academic stress can a short wellbeing questionnaire actually predict — and which factors genuinely drive that signal?

A complete regression and classification study over 129 usable survey responses. Eight regression models and seven classifiers were compared under identical repeated cross-validation, with a tuned Random Forest and an RBF-kernel SVM coming out in front. Feature importance is triangulated across impurity, permutation and SHAP, and group differences are checked with Kruskal–Wallis tests rather than eyeballed. Trained pipelines embed imputation, scaling and encoding so raw records can be scored directly, and ship behind a small Tkinter dashboard.

  • 0.637CV MAE (regression)
  • 0.610CV macro F1
  • 0.720Hold-out ROC-AUC

03 Data Analysis · Predictive Modelling

Salary Prediction

Turning 13,411 messy crowdsourced survey responses into a model.

The problem Can someone’s demographics and employment profile predict which salary band they fall into — and which factors explain the variation in annual pay?

Built on the public Ask A Manager Salary Survey 2024 (13,411 responses, 21 variables). The bulk of the work is the data engineering: standardising 15+ currencies to a common basis, collapsing high-cardinality columns such as industry and country, and using hierarchical and K-Means clustering to encode age, experience and work-mode bands. A hard-voting ensemble of Decision Trees, KNN and Logistic Regression predicts Low/Medium/High salary bands, while linear regression and a 300-tree Random Forest rank the drivers of pay. Findings are reported as descriptions of this self-selected dataset, not population-level claims.

This Portfolio Site

Hand-written front end — no framework, no build step.

The problem Give recruiters a fast, accessible place to see what I’ve built, without reaching for a template.

Written from scratch in semantic HTML, modern CSS and plain JavaScript with zero dependencies.
