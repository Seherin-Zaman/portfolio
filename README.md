# Portfolio — Seherin Zaman

Personal portfolio site for Seherin Zaman, a Computer Science (AI) student at Nottingham Trent University.

## Live Site

https://seherin-zaman.github.io/portfolio/

## Tech Stack

- **HTML5** — plain, hand-written markup
- **CSS3** — custom styles, no framework
- **JavaScript** — vanilla, no libraries

No framework, no build step, no dependencies. The site is static files served as-is.

## Run Locally

Clone the repo:

```bash
git clone https://github.com/Seherin-Zaman/portfolio.git
cd portfolio
```

Then either open `index.html` directly in your browser, or serve it over HTTP:

```bash
python -m http.server 8000
```

and visit http://localhost:8000.

## Project Structure

```
index.html           # page markup and content
style.css            # all styling
script.js            # interactive behaviour
seherin_profile.jpg  # profile image
```
